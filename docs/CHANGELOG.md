本项目以内部协作方式演进，提交采用中文 `type(scope)` 规范（见 README「贡献指南」）。

本文件**面向使用者**，只记录对外有影响的变更；纯内部工程细节（类型收敛、测试、CI 调整等）已省略，完整历史见 Git 提交记录。

## v0.3.0 (2026-08-11)

> 距 v0.2.0（2026-08-07）以来的累计发布：JWT 认证与 RBAC、钉钉群消息/系统推送补全、会话上下文质量重构、还原度提升、前端性能优化、安全加固与文档站重设计。

### 核心亮点
- **安全加固**：JWT 认证 + RBAC（admin/operator/viewer）取代原有弱校验；签名密钥不再硬编码（`config.web.jwt_secret` 惰性解析 + 进程随机兜底，重启后旧令牌失效）；异常信息不再外泄；新增 IP 白名单防 SSRF。
- **会话上下文质量重构**：历史消息顺序归一化，修复「对话已闭环仍追问」「旧话题串味」「老消息误触发回复」；发言人姓名全链路暴露、不同人绝不跨人合并；话题边界加时间标注与断层提示。
- **钉钉群消息 / 系统推送补全**：群聊与「工作通知」此前长期拉取不到，现已通过逐群接口 + 群枚举缓存修复（实测可达 117 个群）。
- **还原度（fidelity）提升**：低置信风格回退由「中性客服」改为「有个性的人」；RAG 空结果注入风格保持指令；清洗管线误伤阈值放宽；上下文/长度上限放宽。
- **存储自愈**：存量分库列迁移自愈，修复 `no such column` 导致的 500；撤回消息改为软标记（Web 端显示「已撤回」）。
- **前端性能优化**：Chart.js 按需懒加载、FontAwesome 双字重子集、图片缩略图 WebP、仪表盘三路轮询合并为单通道、记忆列表分页。
- **文档站重设计**：品牌渐变落地页 + 设计系统（深色优先）。

### 升级注意
- 新增可选配置项 `config.web.jwt_secret`：不配置时每次启动生成进程随机密钥（重启后旧令牌全部失效），建议固定为高熵值（`secrets.token_urlsafe(48)`）。
- 上下文/长度参数默认值放宽（`history_tiering_recent` 4→8、`history_window` 6→12、`history_days` 3→7 等），无破坏性变更。

## v0.2.0 (2026-08-07)

> 距 v0.1.0（2026-08-04）以来的累计发布：会话门控重设计、业务逻辑查缺补漏、多项缺陷修复与质量优化、CI 加速。

### 核心亮点
- **会话门控双重校验**：抽出共用门控裁决，在「进入 LLM 前（前置过滤，省 Token）」与「发送前（并发兜底）」两道关卡接线，任一命中即放弃自动回复；重接 DWS 已读闸门，人工沟通时 bot 绝不插嘴。
- **业务逻辑查缺补漏**：修复账号隔离（硬编码路径导致钉钉账号共用命名空间）、会话库级联清理漏图、SQLite 连接泄漏、配置模板幽灵工具等真实缺陷。
- **CI 加速**：依赖安装改用 `uv` 缓存，热路径由 ~1-2min 降至 ~10-30s。

### 升级注意
- 新增配置项 `poller.suppress_when_owner_read`（默认 `true`）；无需改动既有配置。

## 2026-08-14 · 仪表盘与 RAG 体验优化

- **仪表盘首页一屏化**：系统概览、决策追踪、最近消息、实时日志全部收纳在首屏，无需滚动。
- **决策追踪/最近消息卡片高度优化**：决策卡片加高避免内容截断；实时日志移除 120px 高度限制，真正填满面板。
- **决策历史表格体验**：取消横向滚动条，列超长自动截断、悬停显示完整。
- **工具调用排行布局**：卡片改为自适应网格，避免挤在左侧；面板增加内边距。
- **RAG 记忆列表**：对象名列改显示真实人名/群名；表头改为 Excel 风格（冻结表头 + 网格线）；去掉「会话」列与「对象类型」筛选。
- **DWS 版本自检**：修复「新版本可用」与 beta 通道漏报。

## 2026-08 上旬 · 重要变更摘要

- **安全（P0）**：JWT 硬编码密钥漏洞修复；payload 解析由 `eval` 改为 `json.loads`；异常信息脱敏；敏感数据脱敏工具；IP 白名单防 SSRF；视频/语音消息误判为图片的缺陷修复（避免整段视频被下载 OCR 并造成 ~30s 回复延迟）。
- **回复质量**：修复「对话已结束 AI 仍追问」（改为暴露发言人姓名、交由 LLM 自判，不堆正则门控）；新增话题边界软提示；新增消息年龄门槛（远古消息不触发回复）；撤回消息软标记。
- **稳定性**：存量分库列迁移自愈；list-all 路径漏存本人消息修复；防抖去重收紧（内容相同**且**时间差 ≤2s 才算重复投递）；钉钉群消息补全（117 群实测可达）。
- **前端**：移除冗余 Bootstrap JS；a11y 焦点 / ARIA 修补；工具调用排行卡片重设计；图片缩略图 WebP；Chart.js 懒加载；三路轮询合一。
- **文档站**：落地页商业级重设计；迁移至自定义 Actions 部署工作流；Python 运行版本统一为 3.14+。

## 更早的重要里程碑

- **多平台物理隔离**：钉钉 / 飞书 / 企业微信各自独立适配器、独立 SQLite 库、独立轮询器，数据互不可见。
- **双进程分离**：Web 与后台轮询器（worker）进程分离，改 Web 代码只重启 web 进程、不打断消息摄入。
- **RAG 混合检索**：BGE 本地离线向量 + BM25 重排序（0.6 + 0.4），置信度门控，低置信度转草稿 / 转人工。
- **审批转交（钉钉）**：10 个审批工具 + 通用审批子系统。
- **智能增强**：长期记忆（按用户隔离、自动压缩归档）、图片 OCR、长对话异步摘要压缩、风格人格抽取。

> 架构与设计详情见 [架构文档](architecture.md) 与 [设计总览](design.md)。
