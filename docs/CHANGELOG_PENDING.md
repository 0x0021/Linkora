## 2026-10-16 (未发布)

> 自 v0.6.4 以来无变更

### 终端日志降噪（焦点模式）

- 新增 `--focus` 焦点模式（`scripts/run_linkora.py` 默认开启，`--no-focus` 关闭）：
  控制台只显示「✅ 收到的新消息 / LLM 回复 / WARNING 及以上告警」，抑制每条消息
  的链路内部噪声（`[发送]` DWS 返回、防抖缓存、意图识别、工具路由、LLM 请求参数
  等，共 20+ 个模块）。文件日志 `logs/linkora.log` 与 Web「实时日志」页不受影响，
  仍为全量。
- 周期性统计降级 INFO → DEBUG：展示摘要/动态摘要「本轮评估发现 N 个待摘要会话」、
  轮询器「轮询统计」（每 12 轮）。需要观察时设 `logging.level: debug`。
- 信号行内容截断提升：收到新消息 50 → 120 字符，LLM 回复 100 → 200 字符，
  保证焦点模式下「发来什么 / 回了什么」看得全。
