> 自 v0.8.0 以来的变更

### 新增：适应「别人转发审批流程给我看」场景（2 个新工具）

别人在聊天里转发审批通知（如「周萍提交的其他合同审批」）时，发起人不是当前用户，
原有三个个人视角工具（我发起的 / 待我处理 / 我已处理的）全都查不到。新增：

- **`approval_list_org`**：以管理员视角按模板 + 时间窗查询**全组织**的审批实例列表
  （可选按状态 / 发起人过滤），拿到实例 ID 后接 `approval_get_detail` 取表单明细即可回答。
  工具描述内置了转发场景的完整查询链路引导。
- **`approval_list_cc`**：查询抄送给当前用户的审批单列表（含表单摘要与跳转链接）。
- **窗口限制自动兜底**：实测钉钉这两类接口有双重硬限制——start/end 跨度 ≤120 天、
  start 不得早于 365 天前，超限报误导性的「时间戳无效」。工具层现自动按 ≤120 天
  分段聚合、起点超一年自动收紧并在结果中标注，LLM 传任意合理窗口都能一次查成
  （`approval_list_initiated` 同步受益）。
- 两个工具均为只读、仅钉钉，已加入白名单 example 与默认白名单；内置工具 47 → 49。
