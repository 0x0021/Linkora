主动触达 & 对话摘要

每天定时把近期的对话摘要推给你（钉钉私聊），后台也能随时看同一份汇总。默认关着，想用再开。

摘要页用一张张卡片把每段对话摆出来：头像、来自哪个平台、几条消息、自动归纳的关键词和待办，一眼看完。今天、昨天、近七天，随时切换。

人工接管 · 门控双重校验

同事在说话时，
AI 绝不插嘴

这是灵桥和那些爱抢话的机器人最大的不同。两层把关，只要同事接手了，AI 就不再重复回、也不再白烧 token。

前置过滤：进大模型之前先看看消息是不是已经读过、回过，该跳过的直接跳过，整段 token 都省了。
发送前复核：真要发出去之前再判一次，防住「生成到一半同事插进来了」这种空档。
已读 / 接管识别：接上已读信号和人工接管标记，宁可保守，也不漏掉该回的追问。

快速开始

十分钟，跑起你的第一个 AI 分身

克隆代码、填好配置、一条命令启动。数据全在你自己的机器或内网里。

# 1. 获取代码
git clone https://github.com/0x0021/Linkora.git
cd Linkora

# 2. 安装依赖（Python ≥ 3.14）
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.lock

# 3. 配置平台凭证
cp config.yaml.example config.yaml   # 填入钉钉/飞书/企微信息

# 4. 启动（双进程：web + worker）
.venv/bin/python scripts/run_linkora.py
