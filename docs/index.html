02

03
RAG / 工具

04
LLM 生成
门控前置过滤后进入生成，省 Token
05

人工接管 · 门控双重校验

人工沟通时，
bot 绝不插嘴

这是灵桥和「会抢话的机器人」最大的区别。两层门控确保真人介入的对话里，AI 不再重复回复、不再浪费 Token。

前置过滤：进入 LLM 前先判消息是否已读 / 已回复，命中即跳过生成，省下整段 Token。
发送前复核：真正投递前再判一次，兜住「生成期间人工状态变化」的竞态。
已读 / 接管识别：接回 DWS 已读信号 + 人工接管标志，保守策略不漏回追问。

快速开始

十分钟，接起你的第一个 AI 分身

克隆仓库、填好配置、一条命令拉起。数据全部留在你自己的机器或内网。

# 1. 获取代码
git clone https://github.com/0x0021/Linkora.git
cd Linkora

# 2. 安装依赖（Python ≥ 3.14）
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.lock

# 3. 配置平台凭证
cp config.yaml.example config.yaml   # 填入钉钉/飞书/企微信息

# 4. 启动
python main.py
