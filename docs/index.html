管理台接口

三步，就能上线。

不用买服务，不用交数据。一台自己的机器就够了。

1

装好

克隆仓库，建虚拟环境，装依赖。

2

填好

复制配置模板，填上模型密钥和平台命令行路径。

3

跑起来

一条命令拉起服务，打开管理台就能看见它在工作。

# 1 · 装好
git clone https://github.com/0x0021/Linkora.git && cd Linkora
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt

# 2 · 填好（至少填 llm.api_key 与平台 cli_path）
cp config.yaml.example config.yaml && dws auth login

# 3 · 跑起来 → http://localhost:8080
.venv/bin/python scripts/run_linkora.py
