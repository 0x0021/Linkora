一条消息的旅程

一条消息，经四层流转

01
Polling Layer
消息采集层
拉取 → 去重 → 合并窗口 → 回复冷却，跨组织的自动跳过，探针一直保活。
02
Rule Layer
规则引擎层
黑白名单 → 意图分类 → 关键词规则，确定性逻辑优先裁决。
03
Agent Layer
LLM 智能层
smart / all / keyword 路由 → 工具选择 → RAG 注入 → 长期记忆召回。
04
Tool Layer
工具执行层
26 个工具统一接口，经平台适配器安全执行，结果回灌对话。

数据流 — 入站消息 → 双重去重 → 规则裁决 → LLM Agent → RAG + 记忆 + 工具 → 回复生成 → 决策落库 → 经适配器发回平台。

四项能力升级

更聪明，也更让人放心

A

没把握，就交还给你

不确定的事不硬编，转你本人或先打草稿等你确认，绝不拿假话凑数。

B

学着像你

从你平时的话里摸准语气，回出来的东西，像是你本人打的，不是机器人腔。

C

引据更准

长文档不切断语义，向量加关键词混排，引的永远是上下文对的那段。

D

越用越准

你每次的反馈都成了教材，用黄金问答集反复回归评测，质量一点点校准上来。
