# 错误码与处理方式

| 错误码 | 含义         | 处理方式                           |
|--------|--------------|------------------------------------|
| 1000   | 系统异常     | 稍后重试                           |
| 1001   | 请求参数异常 | 检查参数完整性                     |
| 1003   | 权益不足     | 调用 query_benefit.py 检查余量，提示用户充值 |
| 1004   | 权益扣除失败 | 重试或联系管理员                   |

遇到错误时展示给用户，不自行猜测或替代方案。
