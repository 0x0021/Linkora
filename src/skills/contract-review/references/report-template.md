# 审查结果报告模板（AI 速审）

执行完 `query_review_result.py`（含 `--poll` 且传入 `--file-name <fileName>`）后，**必须读取** `output/<文件名基础>_review_result.json`，解析 `result` 后按下列结构直接展示审查结果报告。

```markdown
# 合同审查报告

## 审查总结
- **风险等级**：[高/中/低]
- **总结**：[summary.summary]

## 风险批注明细

| 序号 | 风险等级 | 原文摘要 | 审查意见 |
|------|----------|----------|----------|
| 1 | 高风险 | [originalText摘要] | [commentTexts.remark] |
| 2 | 中风险 | ... | ... |

## 文档下载
- 清洁版：[点击下载清洁版合同文档](clearWordPath)
- 批注版：[点击下载批注版合同文档](wordPath)
```

风险等级对应：高风险、中风险、低风险（展示时可用图标：高风险=🔴，中风险=🟡，低风险=🟢）。

**注意**：文档下载 URL 可能较长，展示时需确保链接完整不换行；可用短链接文本 + 完整 URL 或单独代码块展示。
